# Project design assets

All raster assets are saved in `public/assets/`. The built-in image-generation tool was used, guided by the user's selected reference screenshots.

| File | Purpose / prompt specification |
| --- | --- |
| cainta-river-hero.png | Wide illustrative river, multi-arch bridge, sky, mountains, greenery and stone CAINTA sign, matching the supplied scenic visual direction. |
| emergency-kit.png | Blue emergency backpack, water, flashlight and first-aid supplies, pale-blue background, composition weighted right. |
| family-preparedness.png | Filipino family preparing an emergency bag, coordinated blue/yellow illustration, open copy space left. |
| brand-mark-white.png | Preserve navy bridge, yellow sun and cyan/blue waves; replace checkerboard background with solid white, including bridge openings and gaps. No text. |
| footer-wave.png | Preserve shallow cyan/light-blue wave; solid pale-blue-white upper region, opaque navy bottom. No text or checkerboard. |

The initial brand-mark.png is an unused draft with a checkerboard artifact; the UI uses brand-mark-white.png. Source references remain in this directory. No official government seal is used. Imagery does not imply official endorsement or a verified real location photograph.
